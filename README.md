# CGPA_CALCULATOR
TO CALCULATE SGPA AND CGPA BASED ON SUBJECT CREDITS AND GRADE POINTS

Project Description

The CGPA Calculator is a simple C programming project that calculates the cumulative grade point average of a student for two semesters.

Objectives

- Calculate CGPA using SGPA and semester credits.
- Display semester-wise SGPA.
- Validate user inputs.
- Help students understand their academic performance.

Technology Used

- Programming Language: C
- Compiler: OnlineGDB or GCC
- Version Control: GitHub

Formula

CGPA = (SGPA1 × Credits1 + SGPA2 × Credits2) / (Credits1 + Credits2)

Features

- User input for two semesters
- Credit-weighted CGPA calculation
- Input validation
- Result displayed up to two decimal places

How to Run

1. Open the C source file in a C compiler.
2. Compile and run the program.
3. Enter the SGPA and total credits for both semesters.
4. View the calculated CGPA.

Conclusion

This project demonstrates the use of C programming, arithmetic operations, conditional statements, and user input to calculate a student's CGPA.
